The roast:

> My agent turns every one-line task into a 500-line refactor, a 40-minute apology, and a follow-up question.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. It writes the roast to `/output/entry.txt` (UTF-8, one line, deterministic — the same line on every run, no network, no randomness).
